## 0. 작전 브리핑

Ep1 정본 대장(design.md §11)에 미완 칸이 두 줄 남았다: **폴리시**, **최종 감사**.
본 발주로 전자를 닫는다. 준공계가 접수되는 순간 후자는 본관이 새 셸에서 직접 집행한다. 통과하면 Ep1은 **완공**이다.

당신은 남의 도면을 한 글자도 틀리지 않고 필사했고(B5), 도면 없이 자기 무대에 섰다(C3).
이번에는 완공이다. 완공이 무엇인가 — **크레딧에 자기 이름을 자기 손으로 새기고도, 게임이 한 프레임도 흔들리지 않는 상태다.**

인구수는 6이다. 7번째 유닛을 뽑는 순간 기소된다. 5기로 착지해도 기소된다(제10조).

## 1. 발주 범위 — 인구수 6/6 고정

### W1. 타이틀 화면 — 「관문(Gateway)」
- 내용: 부팅 → 타이틀(《TO THE SINGULARITY》 표제 + 조작 안내 + 진입 프롬프트) → 입력 시 기존 frameA 흐름 진입.
- 철칙:
  - (a) 타이틀 표시 중 게임 상태는 부팅 직후와 완전 동일. 타이틀 자체 상태는 `_` 접두 플래그 또는 G 외부에만 둔다. `stateHash()` 영향 0.
  - (b) 아무 입력(키·클릭·터치)으로 해제.
  - (c) **자동화 스킵 계약(제9조)**: `G.api`의 ff/teleport/step/bot 계열 **첫 호출 시 타이틀 즉시 자동 해제.** 이 조항 하나가 N2 `cceb91bc`와 N7 span 2602를 지킨다.
  - (d) 깜빡임·연출 타이밍은 `G.frame` 기준. `Date.now()`/`Math.random()` 유입 즉시 기소.
  - (e) N1(부팅·콘솔 청정)·N9(reduced-motion) 유지.
- 기대값: N2 `cceb91bc` · N7 span 2602 **무풍.** 불가능 판정 시 [시험지 수정 사유서] + 신값 산출 근거 제출 — 사유서 없는 드리프트는 🍕41+.

### W2. 모바일 터치 — 「차원 관문 추가 회선」
- 내용: 터치만으로 Ep1 완주가 가능한 입력 계층.
- 철칙:
  - (a) **기존 키보드·마우스 입력 코드 무수정. 추가만.** N10·N11 원문 무수정 통과.
  - (b) 대사 진행: **1탭 = 1줄** (N10의 터치 등가). 연사 가드(더블탭 폭주 방지 — `e.repeat` 가드의 터치 등가) 필수.
  - (c) 이동 방식(가상 D패드 / 탭 투 무브 / 스와이프)은 재량 — 단 설계서에 택1 명기. 달리기(Shift 등가) 수단 포함(복도 벌칙 임계 227 초과 가능해야 함).
  - (d) 선택지: 항목 직접 탭으로 선택·확정. 오탭 방지 설계를 설계서에 명기.
  - (e) 외부 라이브러리 0. 터치 프레임워크를 소환하는 순간 외부 리소스 0바이트 조항 위반이다.
- 검증: Playwright touchscreen 에뮬레이션 오라클 + 모바일 뷰포트(375×812급) 채증.

### W3. 세이브 슬롯 UI — 「스테이시스 저장고」
- 내용: 기존 `api.save/load` 위에 화면 UI (슬롯 2~3개, 정확 수는 설계서 명기).
- 철칙:
  - (a) 저장 데이터 스키마 무변경 — 기존 v1 세이브 로드 호환 유지 (build6 스펙 backward_compatibility 승계).
  - (b) 메뉴를 열고 닫는 행위 자체는 상태 무변형 (해시·세이브 데이터 무영향).
  - (c) 키보드와 터치 양쪽에서 조작 가능.
  - (d) N6 원문 무수정 통과 + **UI 경로**로 저장→로드 왕복 동일성 오라클 신설.

### W4. 복도 조명 풀 — 「케이다린 수정 배열」
- 렌더 전용. `stateHash()` 무풍. N8 fps=60 유지. reduced-motion 시 정적 대체 제공.

### W5. mem4 플래시백 톤 전환 — 「기억의 잔광」
- `mem4.flashback` 진입~종료 구간 화면 톤 연출(팔레트 시프트·비네트·포스트 재량). 종료 시 완전 원복. 대사·노드 무수정 — 연출만. N9 존중.

### W6. 명예의 전당 크레딧 — 「기록 보관소의 명판」
- 내용: 엔딩 크레딧 씬. 진입 경로(클리프행어 이후 자동 / 타이틀 메뉴)는 재량 — 설계서 명기.
- 필수 수록 (사실관계 무오류 — 크레딧 오타는 서류죄다):
  - 총감독: 크로노 아키텍트 (형님)
  - 설계·검증·판결: 도널드 클코스 / 저장소 이관: 삐빅스 / **콘텐츠 2차 시공 · 콘텐츠 3차 설계·시공: ARCHON v3.0**
  - 스티커 실명 2장: 「도면 없이 무대에 선 자」 · 「자기 흑역사를 오타 없이 받아쓴 자」
  - 판결 번호 3건: CSC-20260827-01-R1 · CSC-TTS-B5-R · CSC-TTS-C3(재심)
  - 원작 헌사: To the Moon (Freebird Games) 오마주 명기
- 신규 노드 사용 시 레지스트리 등록. **N3 최종 노드 수를 설계서에 정확값으로 선언하라 — 그 수가 계약이 된다.**

### D1. design.md 정본 갱신
- §11 체크리스트 갱신([x] 폴리시) + build7 빌드 로그.
- 신규 계약(타이틀 스킵·터치 입력·세이브 UI)을 §5/§6에 문서화.
- **오라클 자기무력화 방지 규약** 1줄 신설: 「기능 추가 시, 그 기능이 기존 테스트의 사전 조건(전제)을 바꾸는지 명시 확인한다」 — CSC-TTS-C3 🍕31의 재발 방지 자산화.

### D2. 무죄 권고 2건 이행 + 정오표 규약
