## 3. 인구수 6/6 상세 설계

### W1. 타이틀 화면 — 「관문(Gateway)」
- **위치**: `episode1.html` render() 및 live input / api 계약부
- **구현**:
  - 초기 부팅 시 `G._title = true`.
  - 렌더러: CRT 타이틀 로고 《TO THE SINGULARITY》, 부제 `Episode 1: 각주 0개`, 깜빡이는 프롬프트 `[ 아무 키나 눌러 시작 · PRESS ANY KEY ]` (`G.frame % 60 < 35`), 키보드/터치 조작 안내 렌더링.
  - 해제: 임의 키 입력, 마우스 클릭, 화면 탭 시 `G._title = false` 전환 및 1프레임 입력 소비.
  - **제9조 스킵 계약**: `G.api.step()`, `G.api.ff()`, `G.api.teleport()`, `G.api.autoplay()` 진입 시 `G._title = false` 즉시 해제.
- **수용 기준 (N17)**:
  - 부팅 직후 타이틀 활성화 확인.
  - 타이틀 표시 중 `G.api.hash()`가 `'cceb91bc'`와 일치.
  - 키/클릭/탭 입력 시 타이틀 해제 및 정상 게임 진입.
  - API 호출 시 타이틀 자동 스킵 및 N2/N7 무간섭.

### W2. 모바일 터치 — 「차원 관문 추가 회선」
- **위치**: `episode1.html` 이벤트 리스너 및 렌더러
- **구현**:
  - `touchstart`, `touchmove`, `touchend`, `touchcancel` 이벤트 리스너 등록.
  - **가상 컨트롤러 (D-패드 & 달리기 토글)**:
    - 좌하단: 4방향 D-패드 (터치 영역 `x: 10~110, y: 160~260`).
    - D-패드 중앙/상단: `[RUN]` 토글 버튼 (터치 시 `live.run = true` 전환 -> 속도 5.0 px/f = 300 px/s로 복도 227 px/s 임계 초과 가능).
  - **우하단 액션 버튼**:
    - `[ E ]` 상호작용/대사 버튼 (대사 진행 1탭=1줄, 8프레임 탭 쿨다운 가드로 연사 폭주 차단).
  - **선택지 직접 탭**:
    - 대사 선택지 표시 중 해당 옵션 박스 영역(상하 2분할) 터치 시 오탭 방지 영역 계산 후 즉시 `chooseOption(0)` 또는 `chooseOption(1)` 실행.
  - **외부 라이브러리 0바이트**: 순수 캔버스 좌표 계산.
- **수용 기준 (N18)**:
  - Playwright touchscreen 에뮬레이션으로 터치 탭 대사 1줄 진행 및 연사 가드 작동 확인.
  - D-패드 터치 이동 및 RUN 터치 시 복도 속도 > 227 px/s 달성 확인.
  - 선택지 직접 탭 분기 동작 확인.

### W3. 세이브 슬롯 UI — 「스테이시스 저장고」
- **위치**: `episode1.html` render() 및 live input
- **구현**:
  - HUD 우상단 `[기록 / SAVE]` 버튼 추가 및 단축키 `M` / `Escape` 지원.
