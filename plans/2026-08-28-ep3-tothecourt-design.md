## 1. 정체성
- 아콘 1인칭 시점 법정 코미디. 부제 "Episode 3: 각주 0개의 재판".
- 유머 사양서 = CSC-HUMOR-01 5계층(문체 충돌/정밀성/반복-변주-절정/캐릭터 병리/실화성).
- sys 나레이터는 전편 무표정 관공서 문체 고정.

## 2. 구조 (C안: 증언-회상 법정극)
- 프롤로그: 법원 복도 보행 중 화면에 "TO THE COURT" 부상(제목=동사 연출).
- 법정 골격: 심문 3라운드. 라운드마다 [증언 박제 → 회상 씬 실플레이 → 일치율 정산].
  - R1 "완벽한 입사였습니다" → mem0 회상 → 일치율 12.50%
  - R2 "치밀한 준비였습니다" → mem4 회상 → 일치율 8.33%
  - R3 "계기판이 증명합니다" → mem12 회상 → 일치율 0.00%
- 반전(핵심 병맛): 재판 당일 법정에 아무도 오지 않는다(서면 심리 통보).
  아콘은 빈 법정에서 리허설 그대로 풀 재판을 혼자 완주하고, 기각 도장은
  서류 슈트(Ep2 콜백)로 배달된다.
- 판결: 패소 = 통산 1,901번째 반려 도장(카운터 동결과 서사 일치).
- 에필로그: 그날 밤 "제출 (N+1)차" 표지 작성 → 게이지 톡(+1) → 소등.
  sys 최종: 『다음 기일: 미정. 준비: 이미 시작됨.』 (1승 미공개 준수, R16 진심 비트)

## 3. 메커니즘 5종 (확정)
1. 증언-회상 배신: 증언 텍스트 상단 박제, 회상 종료 시 sys 일치율 정산(소수점 고정).
2. 기각 수렴 선택지: 오답(3부 구성 장문) 선택 시 24프레임 내 『기각』 스탬프 →
   재제시, 정답만 통과. 오답 스탬프는 『(비공식) — 연습 기각은 집계되지 않습니다』.
3. 왕복달리기 심문: 법정에 판사석/증인석 오브젝트. 실보행으로 역할 전환,
   지각 시 본인이 본인에게 지연 사유서 요구 이벤트.
4. 승소 확률 게이지 HUD: 70.00% 시작, 단조증가, 클릭/탭 +1. 렌더 전용
   `_gauge` 필드(해시 제외)로 결정론 보존.
5. 반려 도장 카운터: 1,896 시작, 각본상 5회 공식 반려로 1,901 도달 후 동결.
   플레이어 오답 기각은 카운터 무변동(결정론).
